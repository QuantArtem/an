## Известные пробелы покрытия

| Пробел | Причина | План |

| BR-04 / US-12 — истечение резерва | Срабатывает по таймеру через 5 суток; для автотеста нужен управляемый источник времени | Вынести время в инжектируемую зависимость либо добавить операторское действие по аналогии с FR-11 |
| Срабатывание `storage_expiry_job` по таймеру | E2E проверяет ту же логику через операторское действие, но не сам планировщик | Интеграционный тест с `STORAGE_TTL_SECONDS=1` на отдельном стенде |

## Как смотреть контракты

- **OpenAPI** — открыть файл в [Swagger Editor](https://editor.swagger.io/) или любом IDE с предпросмотром.
  На запущенном стенде у каждого сервиса также есть автоматически сгенерированный Swagger UI:
  `http://localhost:8001/docs` … `8004/docs`.
- **AsyncAPI** — открыть файл в [AsyncAPI Studio](https://studio.asyncapi.com/).
- **Диаграммы** — Mermaid, отображаются прямо на GitHub.

## Система идентификаторов

| Префикс | Что обозначает | Где определён |
|---------|----------------|---------------|
| `BG` | Бизнес-цель | Видение |
| `P`, `C`, `A`, `Q` | Проблема, ограничение, допущение, открытый вопрос | Видение, бизнес-правила |
| `BR` | Бизнес-правило | Бизнес-правила |
| `US` | Пользовательская история | Истории |
| `UC` | Сценарий использования | Сценарии |
| `FR` / `NFR` | Функциональное / нефункциональное требование | Требования |
| `ADR` | Архитектурное решение | adr/ |
| `SD` | Диаграмма последовательности | sequences.md |
| `INT` | Интеграционный поток | Каталог интеграций |
| `TC` / `RC` | Тест-кейс / проверка отказоустойчивости | Тест-кейсы |
| `R` | Риск | Реестр рисков |
| `TD` | Технический долг | Дорожная карта |
